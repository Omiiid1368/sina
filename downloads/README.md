فایل `neon-rush-itch.zip` را بدون تغییر در itch.io آپلود کنید؛ `index.html` در ریشهٔ آرشیو قرار دارد. فایل `neon-rush-source.zip` کد کامل، تست‌ها، راهنمای توسعه، راهنمای انتشار و تصویر کاور را دارد.

## Integrity

The adjacent `.sha256` files contain the verified SHA-256 digests. These ZIPs are the tested delivery artifacts. To build a newer version from source, run `npm run build`; it writes new archives under `artifacts/`.
