# ۱۰۰۰ زیست — نسخهٔ ۰٫۱۴٫۰

برنامهٔ فارسی و راست‌به‌چپ زیست‌شناسی برای Android 8 و بالاتر، ساخته‌شده با Kotlin و Jetpack Compose. تمرین، آزمون، دوئل با حریف رایانه‌ای، مطالعه و ثبت پیشرفت به‌صورت آفلاین انجام می‌شوند. نسخهٔ برنامه `0.14.0`، کد نسخه `6` و شناسهٔ بسته `ir.hezarzist` است.

بانک اصلی **۹۶۲ تست** دارد؛ **۱۹۷ تست بسیار دشوار** با همان شناسه در بانک اصلی هم حضور دارند. شمار کل تست‌های یکتا **۹۶۲** و شمار تمرین‌های نهایی **۷۲** است. انتخاب پایه و فصل، تحلیل گزینه‌ها، تصاویر سؤال و پاسخ و پیشرفت محلی همراه برنامه‌اند.

بستهٔ سورس شامل کد برنامه، منابع و قلم‌ها، آزمون‌ها، Gradle Wrapper، بانک‌های جاری و ابزارهای اعتبارسنجی است. بستهٔ بانک، JSONهای قابل ویرایش، فهرست منابع و مجوزها و همهٔ تصاویر مورد ارجاع را با مسیر اصلی آن‌ها دارد. بستهٔ یک‌جا APK، ZIP سورس، بانک‌های JSON و راهنماهای همین نسخه را کنار هم قرار می‌دهد.

برای حفظ پیشرفت، پیش از نصب پشتیبان محلی بگیرید و APK را به‌صورت به‌روزرسانی روی نصب موجود نصب کنید.
