# بانک تازهٔ ارتقای ۰٫۱۰

بانک فعال چهارگزینه‌ای: `content/questions.json`؛ بانک تمرین تشریحی: `content/finals.json`. نسخهٔ یکسان آن‌ها همراه APK در `app/src/main/assets/` قرار دارد. فایل‌ها UTF-8 و آرایهٔ JSON هستند و قابل ویرایش‌اند.

این بانک از سؤال‌های مستقل تألیفی تشکیل شده و جایگزین کل بانک فعال قبلی است. نام محصول «۱۰۰۰ زیست» باقی می‌ماند؛ تعداد واقعی نمایش داده می‌شود. این نمونه، تکمیل آرشیو کنکور ۱۳۹۸ تا ۱۴۰۵ یا امتحانات نهایی رسمی نیست. هیچ سال، نوبت، کد دفترچه یا شمارهٔ سؤال واقعی جعل نشده است. منابع و وضعیت مجوز در `sources.json` و `licenses.json` ثبت شده‌اند.

سؤال‌های چهارگزینه‌ای چهار گزینه، کلید با اندیس صفر، چهار تحلیل هم‌ردیف، پاسخ تشریحی، دام آموزشی، ارجاع موضوعی، برچسب و منشأ دارند. صورت‌های تشریحی پاسخ معیار، بارم پیشنهادی جمع‌پذیر و دادهٔ لازم برای خودارزیابی دارند؛ مقایسهٔ کلمه‌به‌کلمه و نمره‌دهی خودکار ادعا نمی‌شود.

منبع نگارشی تازه در `author_mcq*.py` و `author_finals*.py` است. `python3 content/v2/build.py` آن‌ها را به JSON تبدیل می‌کند؛ این فرمان تغییر دستی JSON را بازنویسی می‌کند. برای اصلاح مستقیم بانک، فقط JSON اصلی را ویرایش کنید و سپس `python3 tools/sync_bank.py` و `python3 tools/validate_bank.py` را اجرا کنید. کلید و تحلیل‌ها هنگام جابه‌جایی گزینه‌ها باید با خود گزینه جابه‌جا شوند.

نسخهٔ پیشین با ۱۰۰۰ سؤال در `content/legacy/v1/` نگهداری می‌شود و در assets یا انتخاب سؤال فعال نیست. SHA256 بانک اصلی آن `658ba02f02c328a181dec584c878ed46e81ed469e1cdf3ae8af69898fcc40cf7` است. گزارش‌های علمی نسخهٔ پیشین، تأیید این بانک تازه محسوب نمی‌شوند.
