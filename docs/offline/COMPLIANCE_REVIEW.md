# بازبینی مستقل نسخهٔ آفلاین

> **به‌روزرسانی پس از اجرای مرکزی، ۸ نوامبر ۲۰۲۶:** ساخت Release/Bundle/Debug و test APK و ۴ آزمون JVM ثبت شده‌اند. آخرین نتیجهٔ هر ۴۰ آزمون یکتا روی Debug و نیز روی خود APK امضاشدهٔ Release قبول است. در Release، اجرای کامل ۳۹ قبول و ۱ شکستِ ورودی آزمون داشت و بازاجرای هدفمند همان ۱ آزمون پس از اصلاح صرفاً آزمون قبول شد؛ همهٔ ۴۰ آزمون بعد از این اصلاح دوباره یک‌جا اجرا نشده‌اند. خطای ابزارِ تلاش اول Release و شکست برابری زمانِ اجرای اول Debug نیز در [گزارش مرکزی](TEST_REPORT.fa.md)، [خلاصهٔ Debug](test-evidence/device-summary.json) و [خلاصهٔ Release](test-evidence/signed-release-summary.json) حفظ شده‌اند. ارتقای امضاشدهٔ کد ۱ به ۳، نصب تازه در حالت پرواز، انتخاب‌گر واقعی خروجی/بازیابی و ماندگاری پس از force-stop با حدود شواهد مشخص ثبت شده‌اند. متن باقی‌ماندهٔ این سند یادداشت بازبینی منبع **پیش از اجرای مرکزی** است؛ عبارت‌های «آماده» یا «در انتظار اجرا» در بخش‌های بعد، وضعیت زمان تهیهٔ آن یادداشت را بیان می‌کنند. آرشیو رسمی همچنان صفر و ناقص و [دروازهٔ تکمیل نهایی](test-evidence/final-completion-gate.txt) ناموفق است؛ آمادهٔ انتشار عمومی معرفی نمی‌شود.

این گزارش به نسخهٔ `0.11.0-offline-preview` مربوط است. بازبینی منبع، آماده‌سازی آزمون و اجرای آزمون سه وضعیت جدا هستند؛ آماده‌بودن آزمون به‌معنای قبولی APK نیست. نتیجهٔ اجرای دستگاه و اثرانگشت APK باید در گزارش نهایی ساخت توسط اجراکننده ثبت شود.

## وضعیت دامنه و محتوای واقعی

- بانک رسمی کنکور واردشده و تأییدشده: **صفر سؤال**. جدول پوشش سال‌های ۱۳۹۸ تا ۱۴۰۵، وضعیت فهرست آزمون‌ها را «نامشخص» نگه می‌دارد؛ شمارهٔ دفترچه، نوبت و تعداد مورد انتظار حدس زده نشده است.
- بانک مکمل: **۹۶ تست تألیفی مستقل**؛ دهم ۲۸، یازدهم ۳۶، دوازدهم ۳۲. این بانک جایگزین سؤال کنکور مفقودشده نیست.
- آمادگی نهایی: **۷۲ سؤال تألیفی** با بارم پیشنهادی؛ واردکردن سؤال رسمی امتحان نهایی نیز تأیید نشده است.
- تصاویر و دو قلم فارسی همراه APK هستند. بازبینی مستقل محتوای تألیفی پیش‌تر در `docs/v2/research/INDEPENDENT_REVIEW.fa.md` ثبت شده است؛ تأیید انسانی دبیر و تطبیق چاپ رسمی کتاب‌ها هنوز انجام نشده است.
- شرط اصلی کاربر دربارهٔ آرشیو جامع رسمی برآورده نشده است. این نسخه را نمی‌توان نسخهٔ کامل یا آمادهٔ انتشار عمومی معرفی کرد. جزئیات کمبود واقعی و محدودیت دسترسی در `archive/SOURCE_GAPS.fa.md` آمده است.

## بازبینی منبع

| مورد | وضعیت بررسی |
| --- | --- |
| مجوز شبکه، اطلاعات تماس و دسترسی عمومی حافظه | Manifest فعال هیچ `uses-permission` ندارد؛ آزمون Manifest نصب‌شده نیز آماده شده است. |
| پشتیبان‌گیری ابری سیستم | `android:allowBackup="false"` است؛ انتقال پیشرفت فقط با انتخاب فایل توسط کاربر انجام می‌شود. |
| محتوای بسته‌بندی‌شده | `StudyAssets.open` فقط assets APK را باز می‌کند؛ URL، مسیر خارج پوشه و snapshot دانلودی قدیمی را نمی‌پذیرد. |
| قلم و راست‌به‌چپ | دو قلم محلی و `supportsRtl=true`؛ چیدمان Compose راست‌به‌چپ است. |
| حریف رایانه‌ای | صفحهٔ انتخاب و مسابقه صریحاً «حریف رایانه‌ای» و شبیه‌سازی پاسخ را بیان می‌کنند. |
| حفظ سابقهٔ نسخهٔ اول | `ProgressStore` دوباره همان `hezarzist_progress_v1` را استفاده می‌کند؛ پاسخ‌ها و نشان‌های شناسه‌های خارج بانک فعال بایگانی می‌شوند و امتیاز/رکوردها باقی می‌مانند. |
| جلوگیری از بازنویسی پس از بازیابی | epoch محلی، ذخیره‌کننده‌های قدیمی را از نوشتن بازمی‌دارد؛ ریشهٔ Compose پس از تغییر محلی داده را بارگیری می‌کند. |
| بازیابی فایل محلی | allowlist فقط پیشرفت/تنظیمات/نام و آواتار را می‌پذیرد؛ checksum، UTF-8، کلید تکراری، عمق JSON و سقف ۱۶ مگابایت پیش از نوشتن بررسی می‌شوند. journal داخلی، rollback و epoch برای قطع نوشتن قدیمی وجود دارد؛ قبولی تزریق خطا را اجرای دستگاه تعیین می‌کند. |
| مهاجرت نسخهٔ آنلاین آزمایشی | cache مطالعاتی ناشناس v2 و کاربر منتخب جداگانه محفوظ می‌مانند؛ با سابقهٔ دارای دادهٔ v1 ادغام نمی‌شوند. دادهٔ حساب/تماس/توکن وارد پشتیبان نمی‌شود. دادهٔ قدیمی نامعتبر در پروندهٔ خام جدا با اعلان روشن برای اصلاح نگهداری می‌شود. |

## یافتهٔ اصلاحی زمان‌سنج

بازبینی مستقل نشان داد بازگردانی MCQ با `deadlineWall - now` می‌توانست پس از عقب‌رفتن ساعت، زمان باقی‌مانده را افزایش دهد. مالک کد، checkpoint ساعت یکنواخت و بودجهٔ زمان ذخیره‌شده را اضافه کرده است. دو آزمون رگرسیون، تغییر ساعت دیواری و تغییر مبدأ ساعت یکنواخت پس از راه‌اندازی دوبارهٔ دستگاه را بدون دست‌زدن به ساعت واقعی شبیه‌سازی می‌کنند. قبولی این اصلاح باید در خروجی اجرای آزمون تأیید شود.

در یکپارچه‌سازی پشتیبان نیز ناسازگاری validator با مقدار رشته‌ای فیلتر مرور نهایی، فیلدهای تازهٔ ساعت MCQ، قالب نشست‌های بایگانی‌شده و خاموش‌بودن BuildConfig به مالکان گزارش و اصلاح منبع آن‌ها دوباره خوانده شد. مسیرِ ازقلم‌افتادهٔ پیشرفت ناشناس v2 نیز با recovery جداگانه اصلاح شد. قبولی آزمون رفت‌وبرگشت پشتیبان پس از استفاده از هر دو بخش، همراه مهاجرت cache ناشناس v2، همچنان باید با اجرا ثبت شود؛ صرف بازشدن صفحهٔ پشتیبان کافی نیست.

## آزمون‌های آماده‌شده، هنوز بدون ادعای اجرا

`app/src/androidTest/java/ir/hezarzist/OfflineComplianceTest.kt` پنج دروازهٔ انطباق دارد:

1. مجوزهای APK نصب‌شده، پشتیبان ابری خاموش و پشتیبانی RTL.
2. بارگیری تمام ۹۶ تست و ۷۲ سؤال نهایی، توضیح گزینه‌ها، تصویرهای لازم و قلم‌های فارسی از بسته.
3. شمار صفر آرشیو رسمی، هشت سال نامشخص، و نبود فهرست ساختگی دفترچه‌ها.
4. رد URL/مسیر نامعتبر و snapshot قدیمی برای جلوگیری از جایگزین‌شدن محتوای APK.
5. راه‌اندازی در حالت پرواز، دسترسی به صفحهٔ آموزشی، آرشیو ناقصِ صریح و ابزار محلی، و نبود فرم تماس یا دروازهٔ ورود در تنظیمات/پروفایل.

`OfflineGameTest.kt` ده آزمون دارد: هشت سناریوی قبلیِ بانک، امتیاز، مرور، دوئل، زمان، بازیابی نوبت و رکوردها حفظ شده‌اند و دو رگرسیون زمان افزوده شده‌اند. `PersianUiTest.kt` سه سناریوی قبلی فارسی، بازآفرینی Activity، اندازهٔ بزرگ متن و تنظیمات را حفظ می‌کند. ارجاعات این دو کلاس به حساب/همگام‌سازی حذف و انتظار مجوز اینترنت معکوس شده است.

اجراکننده ابتدا emulator را روشن، APK و test APK را نصب و حالت پرواز را فعال کند. مثال دستورات برای محیط دارای Android SDK:

```sh
adb shell settings put global airplane_mode_on 1
adb shell am broadcast -a android.intent.action.AIRPLANE_MODE --ez state true
./gradlew connectedDebugAndroidTest
```

آزمون حالت پرواز صریحاً وضعیت تنظیم سیستم را می‌سنجد و اگر حالت پرواز خاموش باشد، شکست می‌خورد. نصب تازه، ارتقای APK امضاشده از نسخهٔ اول، force-stop و بازکردن دوباره، و خروجی/بازیابی از انتخاب‌گر واقعی فایل همچنان باید روی دستگاه ثبت شوند. این گزارش جایگزین آن شواهد نیست.

## نتیجهٔ فعلی

منبع فعال برای اجرای آفلاین تنظیم شده و اصلاح‌های بازیابی فایل مستقلاً دوباره خوانده شدند؛ اجرای مرکزی آزمون‌ها هنوز در این گزارش تأیید نشده است. آرشیو رسمی و تأیید به‌روز شرایط مایکت همچنان مانع تحویل کامل هستند. هیچ سرور، دامنه، پیامک یا سرویس ایمیل برای تکمیل نسخهٔ آفلاین نیاز نیست.
