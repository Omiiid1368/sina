# جست‌وجوی محدود منابع کنکور در GitHub

در ۷ نوامبر ۲۰۲۶، درخواست‌های عادی HTTPS از همان پراکسی محیط آزمایش شد. API جست‌وجوی `api.github.com` در چهار عبارت با `Tunnel connection failed: 403 Forbidden` رد شد؛ **جست‌وجوی وب خود `github.com` با HTTP 200 در دسترس بود**. از mirror، پراکسی واسط، IP جایگزین یا GitHub برای دریافت دامنهٔ رسمی مسدود استفاده نشده است.

جست‌وجوی مخزن «کنکور زیست» در آن لحظه نتیجهٔ metadata نداشت؛ «konkoor exams» دو مخزن شبیه‌ساز ثبت‌نام و پیش‌بینی آماری نشان داد. جست‌وجوهای عمومی‌تر «کنکور» و «konkoor» به‌ترتیب ۵۵ و ۲۹ نتیجه داشتند؛ فقط صفحهٔ اول برای این بررسی محدود دیده شد. عبارت `کنکور زیست in:readme`، ۲۲ نتیجه داشت و دو سرنخ مرتبط آن بررسی شدند. این تعدادها، شمار **نتایج جست‌وجوی مخزن** هستند و هیچ ارتباطی با شمار آزمون‌ها یا سؤال‌های رسمی ندارند.

## سرنخ واقعی ولی ناکافی

[kgwefvfdjk/konkur-tajrobi-teaching-dataset](https://github.com/kgwefvfdjk/konkur-tajrobi-teaching-dataset)، در commit `1bae6cfef467a7aebaaeff0c912e47092ac1da2e`، مجموعه‌ای واقعی از داده‌های استخراج‌شده، تصاویر برش‌خورده و پاسخ‌های تولیدشده با مدل دارد. README آن ادعا می‌کند ۸۸ سؤال زیست در مجموعه وجود دارد؛ این عدد از خود README است و به‌عنوان شمار سؤال رسمی تأییدشدهٔ پروژه ثبت نشده است.

این منبع برای تکمیل آرشیو قابل پذیرش نیست:

- README صریحاً پوشش ناقص، خطاهای OCR، کلید ناقصِ پارس‌شدهٔ ۱۴۰۴ و کلید پارس‌نشدهٔ ۹۸ را اعلام می‌کند. مجموعهٔ همهٔ نوبت‌ها، داخل/خارج و کدهای دفترچه را اثبات نمی‌کند.
- پوشه‌های `data` و `docs` فایل‌های JSON/JSONL و متن آموزشی دارند؛ `images` پوشه‌های ۱۴۰۲، ۱۴۰۳ و ۱۴۰۴ را نشان می‌دهد. اصل دفترچه و کلید نهایی PDF از مسیرهای بررسی‌شده دریافت نشد. `.gitignore` نیز `*.pdf` را کنار می‌گذارد؛ این موضوع به‌تنهایی اثبات نبود PDF در کل تاریخ مخزن نیست.
- `extract_questions.py` به فایل‌هایی مثل `/root/konkur/Konkur_1402_Tajrobi_Soalat.pdf` روی رایانهٔ نویسنده اشاره می‌کند و `parse_keys.py` الگوی `/root/konkur/*_Kelid.pdf` را می‌خواند. این‌ها مسیر محلی نویسنده‌اند و فایل یا نشانی انتشار رسمی در اختیار این پروژه نمی‌گذارند.
- پاسخ‌ها با مدل تولید و با برابرشدن گزینهٔ پایانی فیلتر شده‌اند. dataset card خودش توضیح می‌دهد این روش صحت گام‌های استدلال، سازگاری با کتاب زیست یا بازبینی انسانی همهٔ سؤال‌ها را تضمین نمی‌کند.
- MIT برای اسکریپت‌ها و متن‌های آموزشی ذکر شده است؛ حقوق سؤال‌های سنجش جدا دانسته شده‌اند. دسترسی عمومی یا MIT ابزار، معادل مجوز مستقل بازنشر همهٔ سؤال‌ها نیست. اعلام اجازهٔ مالک پروژه در پروندهٔ حقوق موجود حفظ شده است.

مدارک: [github-dataset-candidate.json](github-dataset-candidate.json)، شامل نشانی‌های ثابت commit، فهرست فایل‌ها، بخش‌های مرتبطِ سند و SHA-256 **متن بازسازی‌شده از نمایش GitHub**؛ این SHA جای اثر انگشت اصل PDF را نمی‌گیرد.

## ابزار استخراج

[ArminHills/question-statement-extractor](https://github.com/ArminHills/question-statement-extractor)، در commit `a7cbd4ff472d7854b2c5fec97db30537e3ce566d`، ابزار ساخت بانک از PDF و بازبینی است. ریشه و README آن بررسی شد؛ ورودی‌های PDF را از کاربر می‌خواهد و منبع دفترچهٔ اصلی و کلید نهاییِ جامع ارائه نمی‌کند. این بررسی دربارهٔ همهٔ فایل‌های تست یا کل تاریخ مخزن ادعایی ندارد. مدرک: [github-extractor-candidate.json](github-extractor-candidate.json).

## نتیجه و حد بررسی

در این جست‌وجوی محدود، **هیچ جفت اصل دفترچهٔ رسمی و کلید نهایی و هیچ فهرست معتبر همهٔ آزمون‌ها دریافت و تأیید نشد**. وجود dataset جزئی پنهان نشده است، اما دادهٔ انتخابی، OCR تأییدنشده یا پاسخ تولیدمدلی به بانک رسمی منتقل نشده؛ تعداد واردشده همچنان صفر است. نتیجه به معنی نبود هرگونه منبع مناسب در تمام GitHub نیست.

برای ادامه، همچنان اصل دفترچه‌ها، کلیدهای نهایی و اصلاحیه‌ها و شواهد فهرست همهٔ نوبت‌های واقعاً برگزارشده لازم است. دسترسی رسمی یا فایل‌های کاربر باید با آن‌ها تطبیق داده شود. گزارش کامل درخواست‌ها: [github-official-source-probes.json](github-official-source-probes.json). هیچ فایل تولیدیِ اپ، بانک فعال یا نتیجهٔ پوشش به‌دلیل این جست‌وجو تغییر نکرده است.
