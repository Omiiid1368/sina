# استخراج و ممیزی منابع ارسالی

JSONهای نهایی بانک قابل ویرایش‌اند؛ برای ساخت APK، نیاز به استخراج مجدد PDF نیست. اسناد اصلی PDF در ZIP عمومی دوباره بسته‌بندی نشده‌اند؛ نام، SHA-256 و تعداد صفحه در `content/imports/2026-11-08/sources.json` و `report.json` است. تصاویر موردنیاز بانک همراه سورس و APK هستند.

`notro_parser.py` از موقعیت نویسه‌ها، نشان شمارهٔ سؤال/گزینه، جدول کلید و عنوان پاسخ برای استخراج خانوادهٔ مشخص مجموعه‌های نوتروفیل استفاده می‌کند. خروجی خودکار به معنی آماده‌بودن برای بازی نیست. `notro_rationales.py` تحلیل‌های شماره‌دار منبع را تفکیک می‌کند؛ کمبود تحلیل در گزارش انتظار باقی می‌ماند. متن گزینه‌های فعال با استخراج ناحیه‌ای Poppler و تصاویر منبع اصلاح شده است. سه سؤال دارای گزینه‌های صرفاً تصویری، چهار تصویر جدا دارند.

برای ممیزی شمار، حفظ بانک قبلی، کلیدهای مستقل و هش پیکسل همهٔ تصاویر:

```sh
python3 -m pip install Pillow
python3 tools/uploaded/audit_import.py
python3 tools/validate_bank.py
```

برای استفادهٔ پژوهشی از استخراج‌گر، PyMuPDF نیز لازم است. نمونهٔ زیر را از پوشهٔ `tools/uploaded` اجرا کنید:

```python
from notro_parser import parse_pdf
result = parse_pdf({'path': '/absolute/path/to/source.pdf'})
```

جدول کلید مستقل کنترل در assets آزمون Android نگهداری شده است. این ابزارها اصالت دفترچهٔ رسمی، پاسخ علمی، چاپ رسمی کتاب، مجوز مستقل مؤسسه یا تکمیل صفحات تشریحی را تأیید نمی‌کنند. اقلام منتظر نباید خودکار به بانک فعال کپی شوند. پس از ویرایش بانک مرجع، `python3 tools/sync_bank.py` را اجرا و سپس ساخت و آزمون APK را تکرار کنید.
