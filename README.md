# ۱۰۰۰ زیست — پیش‌نمایش آفلاین ۰٫۱۲

اپ فارسی راست‌به‌چپ با Kotlin و Jetpack Compose، برای Android 8/API26 به بالا. نسخهٔ `0.12.0-preview`، کد نسخهٔ ۴، بستهٔ `ir.hezarzist`. امکانات آموزشی، پروفایل اختیاری، زمان مطالعه و ذخیرهٔ پیشرفت کاملاً محلی‌اند؛ حساب، ثبت‌نام، سرور، تبلیغ و تحلیل‌گر بیرونی ندارند. دوئل با **حریف رایانه‌ای** است.

**ورود همهٔ فایل‌های ارسالی و آرشیو جامع هنوز کامل نیست. این خروجی پیش‌نمایش قابل نصب است.**

| محتوای فعال | تعداد |
|---|---:|
| تست تألیفی قبلی، بدون تغییر | ۹۶ |
| تست افزوده از مجموعه‌های ارسالی | ۶۲۹ |
| کل تست فعال | ۷۲۵ |
| تمرین نهایی تألیفی قبلی، بدون تغییر | ۷۲ |
| سؤال رسمی کنکور مستقلاً تطبیق‌شده | ۰ |

۲۷ PDF دریافت، هش‌گذاری و فهرست شدند؛ یک فایل عیناً تکراری است. از ۱۰۷۷ تست استخراج‌شده، ۶۲۹ فعال، ۹ مورد تکراری و ۴۳۹ نیازمند تکمیل/بازبینی‌اند. در این ۴۳۹ مورد، چهار سؤال دارای اعلام اشکال/ابهام در پاسخ‌نامهٔ منبع هستند. ۱۶۵ صفحهٔ تشریحی یکتا هنوز به تطبیق سؤال، زیرسؤال و پاسخ نیاز دارند؛ شمار سؤال‌های آن‌ها معلوم نیست و سؤال تشریحی جدیدی اضافه نشده است. [گزارش دقیق هر فایل و موارد منتظر](docs/offline/v012/IMPORT_REPORT.fa.md)، [شمار پایه و فصل](content/v2/CHAPTER_COUNTS.md).

تست ارسالی با سؤال رسمی تأییدشده یکی نیست. منشأ، ادعای سال، صفحهٔ PDF، هش منبع، کلید مجموعه و نوع تحلیل ثبت شده‌اند. پاسخ‌نامه و تحلیل آموزشی تولیدشده از هم مشخص‌اند. تصاویر سؤال، گزینه‌های تصویری و پاسخ داخل برنامه‌اند و بزرگ‌نمایی دارند. اجازهٔ بازنشر با وضعیت **اعلام‌شده توسط مالک** ثبت است؛ تأیید مستقل حقوق یا بازبینی انسانی علمی ادعا نمی‌شود.

## امکانات جدید

«زمان مطالعه» ثبت دستی با تاریخ شمسی/درس/مدت/یادداشت، زمان‌سنج پایدار با مکث و ادامه، مجموع امروز/هفته/ماه، زیست جدا، هدف روزانه، نمودار، تقویم، ویرایش و حذف تأییدشده دارد. [راهنمای زمان مطالعه و فایل پشتیبان](docs/offline/v012/STUDY_TIME.fa.md) تفاوت بازیابی پس از بستن برنامه و راه‌اندازی مجدد گوشی را توضیح می‌دهد. قالب پشتیبان محلی ۲ مطالعه را هم ذخیره می‌کند؛ قالب قدیمی ۱ همچنان قابل بازیابی است.

«دربارهٔ سازنده» متن درخواستی و تنها دکمهٔ «حمایت از سازنده ❤️» را دارد. لمس دکمه، `https://daramet.com/SinaRajabi` را بیرون برنامه در مرورگر باز می‌کند؛ پشتیبانی اختیاری است. برنامه مجوز INTERNET ندارد. بارگذاری صفحهٔ بیرونی به اینترنت مرورگر نیاز دارد. دسترسی به ضوابط رسمی جاری مایکت در پراکسی با CONNECT403 رد شد؛ سازگاری لینک حمایت با ضوابط فروشگاه **تأیید نشده** و انتشار فروشگاهی انجام نشده است.

## ساخت

JDK 17 یا بالاتر، Android SDK Platform 35 و Build Tools 35؛ Gradle Wrapper 8.9 همراه پروژه است. مسیر SDK را در `local.properties` خصوصی یا متغیر Android SDK تنظیم کنید.

```sh
python3 tools/validate_bank.py
python3 -m pip install Pillow
python3 tools/uploaded/audit_import.py
./gradlew testDebugUnitTest lintDebug assembleRelease
```

Release پیش‌فرض امضانشده در `app/build/outputs/apk/release/app-release-unsigned.apk` است. [راهنمای ساخت و امضا](docs/offline/BUILD.fa.md) و راهنمای اجرای آزمون روی Release همراه‌اند. کلید خصوصی و رمز در سورس عمومی نیستند؛ برای انتشار به‌روزرسانی، کلید محفوظ قبلی لازم است. دریافت اولیهٔ ابزارها اینترنت می‌خواهد؛ اجرای آموزشی APK آفلاین است.

`tools/validate_bank.py --release` عمداً تا رفع کمبود منابع، بازبینی علمی/حقوق و آمادگی مایکت موفق نیست. عدد ۱۰۰۰ نام برنامه است؛ درخواست بعدیِ توسعهٔ بانک، محدودیت عددی نسخهٔ نخست را تغییر داده و شمار واقعی نمایش داده می‌شود.

## فایل‌ها

- `app/`: سورس Compose، منطق بازی، ذخیره‌سازی، زمان مطالعه و آزمون‌ها.
- `content/questions.json` و `content/finals.json`: بانک مرجع قابل ویرایش. پس از تغییر، `python3 tools/sync_bank.py`.
- `content/imports/2026-11-08/`: فهرست منابع، اقلام آماده/منتظر/تکراری، هش تصاویر و گزارش تعداد.
- `app/src/main/assets/imports/`: تصاویر محلی سؤال، گزینه و پاسخ‌نامه.
- `content/legacy/v011/`: نسخهٔ مرجع ۹۶+۷۲ برای کنترل حفظ اطلاعات؛ در بانک فعال تکرار نمی‌شود.
- `content/konkur/`: جدول آرشیو رسمی، فعلاً خالی؛ [کمبود منابع رسمی](docs/offline/archive/SOURCE_GAPS.fa.md).
- `docs/offline/v012/`: مستندات و شواهد نسخهٔ جاری. اسناد نسخه‌های قبل تاریخی‌اند.
- `release/myket/`: پیش‌نویس و موانع واقعی انتشار؛ آمادهٔ ارسال عمومی نیست.

بسته‌ساز، سورس، بانک جدا، ZIP تحویل و checksum می‌سازد؛ کلیدها، `.git`، تنظیمات محلی، cache/build و بخش آنلاین کنارگذاشته‌شده در آن نیستند. تصاویر حجیم در ZIP سورس هستند و در لایهٔ بیرونی بستهٔ یک‌جا تکرار نمی‌شوند.

```sh
python3 tools/package_delivery.py --version 0.12.0-preview --dist dist --self-check --apk /absolute/path/to/signed.apk
```
