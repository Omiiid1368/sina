# ۱۰۰۰ زیست — به‌روزرسانی محتوایی ۰٫۱۳

اپ فارسی RTL با Kotlin/Jetpack Compose برای Android 8/API26 به بالا؛ بستهٔ `ir.hezarzist`، نسخهٔ `0.13.0-content-preview`، کد ۵. آموزش، دوئل با حریف رایانه‌ای، مطالعه و پیشرفت آفلاین و محلی‌اند. APK با گواهی قبلی امضا شده است تا نصب روی نسخهٔ ۰٫۱۲ به‌صورت به‌روزرسانی انجام شود.

**بانک اصلی ۷۶۶ تست، بخش بسیار دشوار ۰، مشترک ۰ و کل یکتا ۷۶۶ است.** ۷۲ تمرین نهایی تغییر نکرده‌اند. ۵۰ تست افزوده و ۹ تست مبهم از فعال کنار گذاشته‌اند؛ سوابقشان در بایگانی محلی حفظ می‌شود. این نسخه تکمیل هدف حدود ۲۰۰۰+۱۰۰۰ سؤال را ادعا نمی‌کند. کمبود بانک اصلی ۱۲۳۴ است. سه QB فشرده دریافت شده‌اند؛ راهنمای رنگ و پاسخ‌نامه لازم است و شمار واقعی تست‌های قرمز واجد شرایط هنوز معلوم نیست.

ورودی بخش بسیار دشوار فقط بعد از وجود سؤال معتبر نمایش داده می‌شود. رنگ، فونت و بخشهای مطالعه، نهایی و دربارهٔ سازنده حفظ شده‌اند. کارت‌های روند توسعه و مجموعه‌های خالی از مسیر آموزشی کنار رفته‌اند. سؤال دارای پاسخ آموزشی به کلید رسمی نسبت داده نشده است؛ تصویر و ارجاع PDF همراه سؤال است. آرشیو رسمی مستقلاً احرازشده همچنان صفر است. بازبینی انسانی علمی و انتشار فروشگاهی ادعا نمی‌شود.

برای ساخت، [راهنمای ساخت](docs/offline/BUILD.fa.md) را بخوانید؛ `python3 tools/validate_bank.py` ساختار و منشأ ثبت‌شده را بررسی می‌کند. `python3 tools/uploaded/audit_content_update.py` حفظ بانک قبلی، دفتر اصلاح/کنارگذاری، شمارها و پیکسل تصاویر جدید را کنترل می‌کند. `audit_import.py` فقط تصویر تاریخی ورود ۰٫۱۲ است. `--release` تا رفع کمبود محتوا و موارد فروشگاهی رد می‌شود؛ قبولی ساختاری جای تأیید علمی را نمی‌گیرد.

لینک‌ها متعلق به شاخهٔ مستقل تحویل‌اند؛ main تغییر نمی‌کند. کلید خصوصی امضا و دادهٔ کاربر داخل سورس یا ZIP تحویل نیستند. پیش از حذف برنامه از فایل محلی پشتیبان بگیرید؛ نصب به‌روزرسانی را بدون حذف نسخهٔ قبلی انجام دهید.
