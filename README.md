# ۱۰۰۰ زیست — پیش‌نمایش آفلاین ۰٫۱۱

برنامهٔ فارسی راست‌به‌چپ با Kotlin و Jetpack Compose برای Android 8 / API 26 و بالاتر. نسخهٔ فعال `0.11.0-offline-preview`، کد نسخهٔ ۳ و شناسهٔ بسته `ir.hezarzist` است. تمرین، آزمون، مرور اشتباهات، دوئل با **حریف رایانه‌ای** و آمادگی نهایی از محتوای همراه برنامه استفاده می‌کنند. حساب، ورود، شماره، ایمیل، همگام‌سازی ابری، تبلیغ یا تحلیل‌گر بیرونی در نسخهٔ فعال وجود ندارد. پیشرفت و پروفایل اختیاری روی دستگاه می‌مانند و انتقال پیشرفت با فایل انتخابی کاربر انجام می‌شود.

**شرط اصلی آرشیو جامع هنوز انجام نشده است.** این سورس و بسته‌های آن پیش‌نمایش‌اند؛ ساخت APK یا قبولی ساختاری بانک به‌معنی تکمیل پروژه یا تأیید علمی آرشیو نیست.

| محتوای فعال | تعداد و وضعیت |
|---|---|
| سؤال رسمی کنکور ۱۳۹۸ تا ۱۴۰۵ | **۰**؛ فهرست معتبر تمام نوبت‌ها، دفترچه‌ها و کلیدهای نهایی هنوز دریافت نشده‌اند |
| تست مکمل تألیفی مستقل | **۹۶**؛ دهم ۲۸، یازدهم ۳۶، دوازدهم ۳۲ |
| تمرین آمادگی نهایی | **۷۲ تألیفی** با بارم پیشنهادی؛ سؤال نهایی رسمی واردشده صفر |

«۱۰۰۰ زیست» نام برنامه است؛ بانک به عدد هزار محدود نمی‌شود و شمار واقعی نمایش داده می‌شود. سؤال تألیفی جای سؤال رسمیِ مفقودشده شمرده نمی‌شود. در این محیط درخواست به منابع رسمی و مایکت در مرحلهٔ تونل پراکسی با 403 رد شده است؛ تعداد مورد انتظار سؤال‌ها و کد دفترچه‌ها حدس زده نشده‌اند. [گزارش پوشش](docs/offline/COVERAGE.fa.md)، [کمبود منابع](docs/offline/archive/SOURCE_GAPS.fa.md) و [شواهد دسترسی](docs/offline/archive/ACCESS_STATUS.json) وضعیت واقعی را ثبت می‌کنند.

## ساخت و بررسی

پیش‌نیازها: JDK 17، Python 3.10 یا بالاتر، Android SDK Platform 35 و Build Tools متناسب با Android Gradle Plugin 8.7.3. Gradle Wrapper 8.9 همراه سورس است. مسیر SDK را با متغیر استاندارد Android SDK یا فایل محلی `local.properties` تعیین کنید؛ این فایل داخل ZIP عمومی نیست. دریافت اولیهٔ ابزارها و وابستگی‌های ساخت اینترنت می‌خواهد؛ کار آموزشی برنامه پس از نصب آفلاین است.

```sh
python3 tools/validate_bank.py
python3 tools/konkur_coverage.py
python3 tools/test_konkur_coverage.py
./gradlew testDebugUnitTest assembleDebug
```

خروجی آزمایشی: `app/build/outputs/apk/debug/app-debug.apk`. این‌ها دستور اجرا هستند؛ این README ادعای قبولی ساخت یا آزمون دستگاه نمی‌کند. دستورهای Release، امضا، نصب در حالت پرواز و بسته‌بندی در [راهنمای ساخت](docs/offline/BUILD.fa.md) آمده‌اند. [گزارش آزمون نسخهٔ جاری](docs/offline/TEST_REPORT.fa.md) ساخت، اجرای Debug و بررسی دستی APK امضاشده، نصب تازه در حالت پرواز، انتخاب‌گر واقعی خروجی/بازیابی و حفظ داده پس از بازکردن دوباره را با نسخه و هش ثبت می‌کند. آخرین نتیجهٔ ۴۰ آزمون یکتا روی خود Release امضاشده نیز قبول است: اجرای کامل ۳۹ قبول و ۱ شکستِ ورودیِ آزمون داشت و بازاجرای هدفمند همان یک آزمون پس از اصلاح صرفاً آزمون قبول شد؛ همهٔ ۴۰ آزمون بعد از آن اصلاح دوباره یک‌جا اجرا نشده‌اند. سوابق شکست‌ها در گزارش محفوظ‌اند؛ [بازبینی انطباق منبع](docs/offline/COMPLIANCE_REVIEW.md) نیز سوابق بازبینی را نگه می‌دارد.

`python3 tools/validate_bank.py --release` علاوه بر ساختار، تکمیل آرشیو و آمادگی انتشار را مطالبه می‌کند و با وضعیت ناقص فعلی نباید موفق تلقی شود. تعداد دقیق هزار شرط این نسخه نیست.

## سورس، بانک و سوابق

- `app/`: رابط Compose، منطق بازی، ذخیرهٔ محلی، مهاجرت پیشرفت، خروجی/بازیابی فایل و آزمون‌های Android.
- `content/questions.json` و `content/finals.json`: بانک مکمل قابل ویرایش؛ نسخهٔ یکسان آن‌ها در assets بسته می‌شود. پس از ویرایش، `python3 tools/sync_bank.py` و سپس اعتبارسنجی را اجرا کنید.
- `content/konkur/`: آرشیو رسمی و جدول پوشش مستقل؛ فعلاً فهرست سؤال‌های رسمی خالی است. ساختار و مسیر ورود اسناد در README همان پوشه توضیح داده شده‌اند.
- `content/v2/`: منابع، وضعیت حق استفاده، شمار فصل‌ها و مواد تألیف بانک مکمل. اسکریپت `build.py` ویرایش دستی JSONها را بازنویسی می‌کند؛ برای اصلاح عادی از JSON مرجع استفاده کنید.
- `content/legacy/v1/questions.json`: مرجع بازیابی و کنترل عدم بازاستفاده از بانک قبلی؛ در بانک فعال APK نیست. امتیاز و سابقهٔ شناسه‌های قدیمی باید از مسیر مهاجرت حفظ شوند.
- `app/src/main/assets/diagrams/` و `app/src/main/res/font/`: تصویرها و قلم‌های محلی؛ مجوز قلم در `docs/FONT-LICENSE.txt` است.
- `docs/offline/`: اسناد مربوط به نسخهٔ آفلاین جاری. `docs/v2/` و گزارش‌های قدیمی ریشهٔ `docs/` **تاریخی** هستند؛ نتایج ساخت، آنلاین یا بانک نسخهٔ قدیم، شاهد آزمون این APK نیستند. اعلام قبلی اجازهٔ مالک با توضیح وضعیت جدید در [پروندهٔ حقوق](docs/offline/archive/RIGHTS.fa.md) خوانده شود.
- `release/myket/`: پیش‌نویس توضیحات، حریم خصوصی، دارایی‌های مستقل و وضعیت آمادگی؛ ضوابط رسمی روز مایکت هنوز خوانده نشده و انتشار انجام نشده است.

ارجاع به کتاب و بازبینی مفهومی با هوش مصنوعی، جای تطبیق چاپ رسمی و بازبینی انسانی را نمی‌گیرد. اجازهٔ بازنشر اعلام‌شدهٔ مالک با وضعیت `USER_DECLARED` ثبت است؛ گواهی مستقل از طرف صاحب اثر معرفی نشده است.

## بستهٔ تحویل

ابزار بسته‌بندی فایل‌های فعال را با فهرست مجاز جمع می‌کند، کلیدها و فایل‌های محرمانه، تنظیمات محلی، cache، log، خروجی build، `.git` و دادهٔ بخش آنلاین کنارگذاشته‌شده را خارج می‌گذارد. کلید امضا در سورس عمومی قرار نمی‌گیرد. بسته‌بندی به‌تنهایی امضا، اجرای APK، تکمیل آرشیو یا پذیرش مایکت را تأیید نمی‌کند.

```sh
python3 tools/package_delivery.py --version 0.11.0-offline-preview --dist dist --dry-run --self-check
python3 tools/package_delivery.py --version 0.11.0-offline-preview --dist dist
```

دو ZIP نسخه‌دارِ سورس و تحویل، به‌همراه گزارش manifest و checksum ساخته می‌شوند. APK یا AAB خودکار از پوشه‌های build/dist برداشته نمی‌شود؛ فقط اگر مسیر واقعی را صریحاً با `--apk` یا `--aab` بدهید، داخل بستهٔ تحویل می‌رود. نمونهٔ کامل در راهنمای ساخت است. APK امضاشده باید پیش از آن جدا ساخته و آزموده شود.
